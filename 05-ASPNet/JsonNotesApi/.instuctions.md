# Student Guide: Building a Persistent JSON Web API

This guide shows you how to adapt the **JsonNoteStore** pattern to build your own persistent Web API for your assignment or project, without needing a database, SQL, or Entity Framework Core.

All data is stored in a simple `.json` file on disk. When your server restarts, your data is still there!

---

## The 4-Part Architecture

Every persistent API in this pattern consists of four simple files:

```
┌─────────────────────────────────┐
│ 1. The Saved Model              │  Defines what an item looks like in storage (with an Id)
│    (e.g., Student.cs)           │
└────────────────┬────────────────┘
                 │
┌────────────────▼────────────────┐
│ 2. The Request Model            │  Defines what the user sends in POST/PUT (with validation rules)
│    (e.g., StudentRequest.cs)    │
└────────────────┬────────────────┘
                 │
┌────────────────▼────────────────┐
│ 3. The JSON File Store          │  Reads and writes the .json file on disk using simple C# methods
│    (e.g., JsonStudentStore.cs)  │
└────────────────┬────────────────┘
                 │
┌────────────────▼────────────────┐
│ 4. The API Controller           │  Handles HTTP requests (GET, POST, PUT, DELETE) and status codes
│    (e.g., StudentsController.cs)│
└─────────────────────────────────┘
```

## Domain Ideas for Your Project

You can adapt this pattern to any domain you choose. Here are four popular ideas:

### 1. Student Directory (University Store)
* **Storage File:** `students.json`
* **Fields:** `Id` (int), `FullName` (string), `Email` (string), `Major` (string)

### 2. Recipe Book
* **Storage File:** `recipes.json`
* **Fields:** `Id` (int), `Title` (string), `CookTimeMinutes` (int), `Ingredients` (string)

### 3. Bookstore / Inventory
* **Storage File:** `books.json`
* **Fields:** `Id` (int), `Title` (string), `Author` (string), `Price` (decimal)

### 4. Task / Project Tracker
* **Storage File:** `tasks.json`
* **Fields:** `Id` (int), `Title` (string), `DueDate` (string), `IsDone` (bool)

## Complete Blueprint: The Student Directory (University Store)

Below is the complete, beginner-friendly code for a **Student Directory API**. You can copy, run, or adapt this directly!

---

### Step 1: Create the Model (`Models/Student.cs`)
This class represents a student saved on disk. It has an `Id` assigned by the server.

```csharp
namespace JsonNotesApi;

public class Student
{
    // The server assigns this unique ID
    public int Id { get; set; }

    // Student information
    public string FullName { get; set; } = "";
    public string Email { get; set; } = "";
    public string Major { get; set; } = "";
}
```

---

### Step 2: Create the Request Model (`Models/StudentRequest.cs`)
This class defines what input users are allowed to send. Attributes like `[Required]` and `[StringLength]` automatically validate the input and reject invalid data with an **HTTP 400 Bad Request**.

```csharp
using System.ComponentModel.DataAnnotations;

namespace JsonNotesApi;

public class StudentRequest
{
    // Name is required, up to 100 characters
    [Required]
    [StringLength(100)]
    public string FullName { get; set; } = "";

    // Email is required and must look like an email
    [Required]
    [EmailAddress]
    [StringLength(120)]
    public string Email { get; set; } = "";

    // Major is required, up to 80 characters
    [Required]
    [StringLength(80)]
    public string Major { get; set; } = "";
}
```

### Step 3: Create the JSON Store (`JsonStudentStore.cs`)
This class manages reading from and writing to `students.json`.
* Notice there are **no complex databases or threading locks**.
* Every method follows the same 3 steps: **1) Read from file, 2) Modify list, 3) Write to file**.

```csharp
using System.Text.Json;

namespace JsonNotesApi;

// Persistent storage for students using a local students.json file.
public class JsonStudentStore
{
    // Path to the JSON file on disk
    private readonly string filePath;

    // Formatting options: WriteIndented = true keeps the JSON human-readable
    private readonly JsonSerializerOptions jsonOptions = new(JsonSerializerDefaults.Web)
    {
        WriteIndented = true
    };

    public JsonStudentStore(IWebHostEnvironment env)
    {
        // Save students.json directly in the project folder
        filePath = Path.Combine(env.ContentRootPath, "students.json");
    }

    // Helper 1: Read all students from students.json into a C# List
    private List<Student> ReadStudentsFromFile()
    {
        // If the file does not exist yet, return a new empty list
        if (!File.Exists(filePath))
        {
            return new List<Student>();
        }

        // Read the text from the file
        string jsonText = File.ReadAllText(filePath);

        // Convert the JSON text into a C# List of Student objects
        var students = JsonSerializer.Deserialize<List<Student>>(jsonText, jsonOptions);

        return students ?? new List<Student>();
    }

    // Helper 2: Write a C# List of students back to students.json
    private void WriteStudentsToFile(List<Student> students)
    {
        string jsonText = JsonSerializer.Serialize(students, jsonOptions);
        File.WriteAllText(filePath, jsonText);
    }

    // 1. GET all students
    public List<Student> GetAll()
    {
        return ReadStudentsFromFile();
    }

    // 2. GET one student by ID
    public Student? GetById(int id)
    {
        List<Student> students = ReadStudentsFromFile();

        // Loop through each student to find the matching ID
        foreach (var student in students)
        {
            if (student.Id == id)
            {
                return student; // Found!
            }
        }

        return null; // Not found
    }

    // 3. POST / Add a new student
    public Student Add(StudentRequest request)
    {
        List<Student> students = ReadStudentsFromFile();

        // Calculate the next available unique ID (starts at 1)
        int nextId = 1;
        foreach (var student in students)
        {
            if (student.Id >= nextId)
            {
                nextId = student.Id + 1;
            }
        }

        // Create the new student object
        var newStudent = new Student
        {
            Id = nextId,
            FullName = request.FullName.Trim(),
            Email = request.Email.Trim().ToLowerInvariant(),
            Major = request.Major.Trim()
        };

        // Add to the list and save to disk
        students.Add(newStudent);
        WriteStudentsToFile(students);

        return newStudent;
    }

    // 4. PUT / Update an existing student
    public bool Update(int id, StudentRequest request)
    {
        List<Student> students = ReadStudentsFromFile();

        // Find the student in the list
        Student? studentToUpdate = null;
        foreach (var student in students)
        {
            if (student.Id == id)
            {
                studentToUpdate = student;
                break;
            }
        }

        // If the student doesn't exist, return false
        if (studentToUpdate == null)
        {
            return false;
        }

        // Update the properties and save to disk
        studentToUpdate.FullName = request.FullName.Trim();
        studentToUpdate.Email = request.Email.Trim().ToLowerInvariant();
        studentToUpdate.Major = request.Major.Trim();

        WriteStudentsToFile(students);
        return true;
    }

    // 5. DELETE a student by ID
    public bool Delete(int id)
    {
        List<Student> students = ReadStudentsFromFile();

        // Find the student in the list
        Student? studentToDelete = null;
        foreach (var student in students)
        {
            if (student.Id == id)
            {
                studentToDelete = student;
                break;
            }
        }

        // If not found, return false
        if (studentToDelete == null)
        {
            return false;
        }

        // Remove from list and save to disk
        students.Remove(studentToDelete);
        WriteStudentsToFile(students);

        return true;
    }
}
```

### Step 4: Create the Controller (`Controllers/StudentsController.cs`)
This controller connects HTTP requests from the browser or Swagger to your store.

```csharp
using Microsoft.AspNetCore.Mvc;

namespace JsonNotesApi;

// [ApiController] automatically checks validation rules from StudentRequest
// [Route("api/students")] sets the URL to: http://localhost:5084/api/students
[ApiController]
[Route("api/students")]
public class StudentsController : ControllerBase
{
    private readonly JsonStudentStore store;

    // ASP.NET Core supplies the store through Dependency Injection
    public StudentsController(JsonStudentStore store)
    {
        this.store = store;
    }

    // GET /api/students
    // Returns 200 OK with all students
    [HttpGet]
    public IActionResult GetAll()
    {
        return Ok(store.GetAll());
    }

    // GET /api/students/1
    // Returns 200 OK with the student, or 404 Not Found
    [HttpGet("{id}")]
    public IActionResult Get(int id)
    {
        var student = store.GetById(id);
        if (student == null)
        {
            return NotFound(); // HTTP 404
        }

        return Ok(student); // HTTP 200
    }

    // POST /api/students
    // Creates a new student. Returns 201 Created and Location header
    [HttpPost]
    [ProducesResponseType(201)]
    public IActionResult Create(StudentRequest request)
    {
        var newStudent = store.Add(request);

        // CreatedAtAction sends HTTP 201 and Location: /api/students/{id}
        return CreatedAtAction(nameof(Get), new { id = newStudent.Id }, newStudent);
    }

    // PUT /api/students/1
    // Updates a student. Returns 204 No Content, or 404 Not Found
    [HttpPut("{id}")]
    public IActionResult Update(int id, StudentRequest request)
    {
        bool wasUpdated = store.Update(id, request);
        if (!wasUpdated)
        {
            return NotFound(); // HTTP 404
        }

        return NoContent(); // HTTP 204
    }

    // DELETE /api/students/1
    // Deletes a student. Returns 204 No Content, or 404 Not Found
    [HttpDelete("{id}")]
    public IActionResult Delete(int id)
    {
        bool wasDeleted = store.Delete(id);
        if (!wasDeleted)
        {
            return NotFound(); // HTTP 404
        }

        return NoContent(); // HTTP 204
    }
}
```

### Step 5: Register the Store in `Program.cs`
Open `Program.cs` and add your store as a **singleton service**:

```csharp
builder.Services.AddSingleton<JsonStudentStore>();
```

Now run your application:
```powershell
dotnet run --launch-profile classroom
```

## How to Test Persistence

1. Open Swagger at <http://localhost:5084/swagger/>.
2. Use `POST /api/students` to add two students.
3. Open `students.json` in VS Code to see your data saved on disk.
4. Stop the server in your terminal with `Ctrl + C`.
5. Start the server again (`dotnet run --launch-profile classroom`).
6. Run `GET /api/students` in Swagger: **your students are still there!**

## Step-by-Step Adaptation Checklist

To adapt this to your own idea (e.g., Recipes or Books):
1. **Choose your fields**: Decide on 3–4 properties (e.g. `Title`, `Author`, `Price`).
2. **Create the Model**: Copy `Student.cs`, rename to your model name (e.g., `Book.cs`), and replace properties.
3. **Create the Request**: Copy `StudentRequest.cs`, add validation attributes (`[Required]`, `[StringLength]`, `[Range]`).
4. **Create the Store**: Copy `JsonStudentStore.cs`, change the filename to your entity (e.g., `books.json`), and update property assignments.
5. **Create the Controller**: Copy `StudentsController.cs`, change the route (e.g., `[Route("api/books")]`), and point to your store.
6. **Register in `Program.cs`**: Add `builder.Services.AddSingleton<YourStore>();`.
